For my next massive build, I am considering rendering Mount Rainier in LEGO. Towards that end, I used AI to write code to help design and visualize these renderings. It fetches USGS elevation data to build a LEGO elevation model and overhead imagery to cast that into available LEGO colors. The tool allows exaggerating the vertical ratio, which I've found looks best for these mountains at 1.5x scale.
